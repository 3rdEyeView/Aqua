All Operators born January 1st, 1988 or later MUST complete the ONLINE Boaters License PRIOR to arrival. Florida State Law requires all operators must pass an approved boaters safety course. TEST IS ONLY AVAILABLE FOR 90 days. Valid State Issued ID also required upon arrival. ( For international Guests a Valid Photo Passport is also acceptable. )
1. Must be age 18+ to rent.

3. Valid photo ID and a temporary boating license is required to rent.
4. Up to 2 people per jet ski.
5. Max weight is 400 lbs. (The more weight you put on jet ski, the harder to maneuver.)
6. Physical requirements: Must be able to lift oneself out of water in the event you fall off.
