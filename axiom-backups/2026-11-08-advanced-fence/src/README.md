# Advanced Fence Service LLC demo assets

Source: https://www.angi.com/companylist/us/sc/columbia/advanced-fence-service-llc-reviews-10165429.htm

Public listing for Advanced Fence Service LLC in Columbia, South Carolina. The Facebook profile image uses the same AFS fence emblem as the Angi logo, which strongly supports the match. Use the wood-tone Facebook logo in the demo. The 16 project photos are square gallery images at 700 × 700 px. The hero candidate is the wood privacy fence.

## Facebook gallery photos

The facebook-gallery folder contains 14 photos extracted from the supplied Facebook gallery screenshots. The screenshot tiles were cropped to remove the grid and resampled to 408 × 408 px with Lanczos interpolation. These are thumbnail-source images suited to small gallery cards.

Use advanced-demo-logo-facebook.jpg for the brand. Start with advanced-demo-hero-wood-privacy.jpg from Angi for the full-width hero and use the Facebook crops throughout the project gallery. For the large photo viewer, use the matching higher-resolution file where available or display the screenshot crop at card size.
